## 2. Judgment calls

1. **Timed drills in the import format.** The parser only accepts `sets x reps`. For holds, breaths and efforts, `reps` = seconds / breaths / efforts (e.g. `90/90 ER Hold 3x25` = three 25-second holds; `BC Straw Breathing 2x10` = two rounds of 10 breaths; `Ramp Up Isometric ER Layback 1x6` = the six-effort ramp). Each template says so in its header. Zone 2 rows are `1x1` and the duration (20–30 min) lives in the exercise description the app shows.
2. **Categories.** The parser only requires a *valid* category; it does not require the library's own category for that exercise. Templates nevertheless use the library's category wherever it makes sense. Two exceptions: `Med Ball Scoop Toss`, `MB Rotational Pass`, `MB Seated Chest Pass` and `Lateral Broad Jump` are tagged **Main Exercises** in the library, so they are placed as the *first* Main row (power before strength) rather than under Speed/Power.
3. **Duplicate names.** Several exercises exist twice (a built-in and a custom copy, e.g. `Lateral Bound`, `Copenhagen Plank`, `Front Squat`). The import matches the first name in `[...BUILT_IN, ...custom]`, so the built-in wins; the scorer does the same.
4. **Session-length model.** Minutes per set by category (Pre-Throwing 0.9, Speed/Power 1.75, sprints 2.5, heavy main sets 3.5, other main 2.5, accessory 1.2, throwing 0.4 min per throw + 5, zone 2 = 25). It is an estimate for checking "about one hour", not a stopwatch. Targets: warn above 60 min, violation above 72. GPP Monday (69) and First-Transition Tuesday (62) run a little long; both are flagged, not failed.
5. **Equipment tier.** The import's equipment check passes when the athlete's tier is unknown. Templates lean on E1 (barbell/trap bar/landmine) in main lifts; alternates list E2/E3 swaps.
6. **Gates.** All gates are off (`GATES_DISABLED` on `main`), and templates contain no gate codes; the scorer fails any template text containing `G1–G4`/`T1–T4`.
7. **In-season week** assumes a once-a-week starter with the game on "Friday". The heavy lift sits three days before and never the day before. For a reliever, drop Lift C and keep two lifts.
8. **The heavy lift** is the Trap Bar Deadlift in every phase (RPE 8, RPE 9 only in SPP). Pitchers' maximal strength evidence is for compound barbell lifts as a class (S17, S18); the trap bar is chosen for shoulder/elbow friendliness, which is a coaching judgment, not a cited result.
9. **Power slot** uses rotational med-ball throws (Tier 1 with a verified correlation, S01) and sprints/jumps whose correlation rows in 3.2 are unsupported but whose *training* evidence as a class is verified (S30, S35, S45). The register says which is which.
10. **Library snapshot committed.** `exports/exercise-library-2026-11-11.json` was untracked; it is committed on this branch so the scorer runs from a fresh checkout. The generated CSV of the same export was not present on disk and is not reproduced.
11. **Correlation-only evidence** is never described as proof that training the exercise raises velocity; the register's evidence-type column and the notes say "correlation only" wherever that applies.
12. **Searches were limited** by rate limits and paywalls (PubMed, PMC, Ovid, core.ac.uk all refused automated fetches). Europe PMC's REST API resolved most citations by PMID/title. Where only a search summary was available, the register says "partial".

## 3. Claims marked unsupported, mismatched or missing

Full table in `evidence-register.md` §4 (26 items). Headlines:

- **Correlation table (3.1 §2.1 / 3.2 §2):** only the rotational med-ball throw row (r = 0.62, p = 0.02) is supported — Taniyama et al. 2021. The loaded jump lunge (r = 0.369), grip strength (0.49), lateral/broad jump (> 0.55), resisted vertical jump (0.52), MB rotational pass (0.68–0.79), backward overhead toss (~0.70), seated chest pass, sit-up throw and shoulder IR (−0.312) rows have **no source**; the broad-jump row is **contradicted** by Taniyama 2021. The 10-yard sprint was tested by Lehman 2013 but its r could not be retrieved. The bench/squat ~0 rows are directionally supported by a 13-pitcher study (Aloi 2019) with different numbers.
- **Named citations:** Lin 2024 (as cited) is mismatched; Fleisig 2023, Sun 2025, Zhao 2026 and Guimarães 2025 were not found; Solomito 2024 (hip IR) is described in summaries but its record could not be resolved; Swinton 2024's "295 studies" was not confirmed; Aguinaldo & Escamilla and Howenstein are 2019 journal papers, not 2018.
- **Blueprint references:** [T6] is cited for the cervical spine but is a trunk-tilt paper; [T1] lists the wrong first author; [T4]'s year is ambiguous; **[S7]–[S9] are cited in sections 7.4–7.5 but absent from the reference list.**
- **Ruling items with no peer-reviewed support, kept because the rulings require them:** the BC Exercise primer (7 drills), shoulder distraction training (proposed as a library gap), finger curls and pinch holds (the 2024 sensor-ball study was not located), `Dry Rep`, `Variable Condition Flat Ground`, `Diaphragmatic Breathing`, `Progressive Muscular Relaxation`, and `Competition` (the game itself). 14 of 90 exercises carry the flag.
